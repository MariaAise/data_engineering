Level 2
SQL Patterns

You can filter, aggregate, and join. This guide covers the six patterns that separate intermediate from advanced SQL: CTEs, window functions, top-N per group, running totals, conditional aggregation, and date arithmetic. Every concept is taught on a single consistent schema with full worked examples.

Schema customers → subscriptions → payments · plans · support_tickets
Prerequisites

These chapters assume you're comfortable with SELECT, WHERE, GROUP BY, HAVING, ORDER BY, LIMIT, JOINs, and basic aggregates (COUNT, SUM, AVG, MIN, MAX). If any of those feel shaky, revisit the Level 1 exercises first.
